How to read these. Squint: the hierarchy (KPIs → tabs → rows → status) should survive in every card — if it does, colour is doing emphasis, not structure. Then ask which temperature suits a finance controller staring at this for hours: cool families (slate, teal, indigo) read analytical and recede; warm ones (clay, graphite+amber) feel more human but fight the red status colour for attention. The data hue is deliberately lighter than the accent in every family so bars never look like buttons. Contrast figures are WCAG 2.1 ratios of each text colour on that card's ground.
